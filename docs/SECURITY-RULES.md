# قواعد الأمان الملزمة

> تُقرأ في كل جلسة (مربوطة من `CLAUDE.md`). أي مخالفة لها تُعامل كخطأ يوقف الدمج.

**هدفنا:** موقع عام لا يُخترق، ولا يتعطل، ولا يستنزف الميزانية.

## ضد الاختراق
- لا أسرار (مفاتيح API أو كلمات مرور) في الكود أو الواجهة أو Git أو السجلات. الأسرار في متغيرات البيئة على الخادم فقط.
- كل مدخل من المستخدم يُتحقق منه بالنوع والطول والحدود (Zod).
- الملفات المرفوعة: التحقق من النوع الحقيقي (لا الامتداد فقط)، وحد للحجم والمدة، وأسماء ملفات يولّدها الخادم، وحذفها بعد التحليل.
- أي رابط يجلبه الخادم (بث أو صورة) يمر بحماية SSRF، بما فيها التحويلات والروابط داخل قوائم HLS.
- لا تمرير لمدخلات المستخدم إلى أوامر النظام (مثل ffmpeg) كنص. استخدم مصفوفة وسائط فقط.
- رسائل الخطأ للمستخدم عامة، بلا مسارات ملفات أو تفاصيل داخلية.
- CORS مقصور على نطاقنا فقط.
- مراجعة `npm audit` قبل كل مرحلة، وإصلاح الثغرات العالية بتحديث مختبر.

## ضد التعطل واستنزاف الميزانية
- حد للطلبات لكل زائر (Rate Limiting) على كل مسار يكلّف، خصوصًا التحليل.
- سقف إنفاق يوقف التحليل تلقائيًا عند الوصول له.
- مهلة زمنية لكل طلب خارجي، وعدد محدود لإعادة المحاولة.
- إذا فشلت خدمة خارجية، الموقع يبقى يعمل ويعرض رسالة واضحة بدل أن يتعطل.

## قواعد العمل
- لا نشر، ولا تفعيل خدمة مدفوعة، ولا أوامر حذف، دون موافقة المستخدم.
- قبل الإطلاق: مراجعة أمنية للقراءة فقط على هذه القواعد، بأدلة من الكود (الملف ورقم السطر)، ثم الإصلاح على دفعات.
